## Design system for Wargakas (Flutter)

Direction: **Trust & Authority, calm minimalism, high legibility** (Swiss/minimal per generated style; variance 2, motion 2, density 4). Keep brand green; drop gold/navy swaps unless rebrand wanted.

### Tokens
- Primary `#006B5B` (current seed, keep). On-primary `#FFFFFF`. Contrast vs white = 6.6:1 OK.
- Surface `#F8FAF8` (current), card `#FFFFFF`, outline `#CBD5D1`, text `#0B1F1B`, muted text `#44534F` (>=7:1 on surface).
- Semantic: success/lunas `#1B7F3B`, warning/sebagian `#8A5A00`, danger/belum+error `#B3261E`, info/sync `#1E5AA8`. Always pair with icon + text.
- Dark: surface `#0F1715`, card `#16211E`, primary tone `#4FD1B5`, text `#E6F0ED` (verify 4.5:1 pairs before shipping).
- Spacing: 4 / 8 / 12 / 16 / 24 / 32. Radius: 12 card, 28 pill buttons/FAB-extended, 8 inputs.
- Elevation: none; 1px outline cards (already `elevation: 0`).

### Typography (google_fonts)
- Headings/numbers: **Lexend** (designed for reading ease). Body: **Source Sans 3**. Both from ui-ux-pro-max "corporate trustworthy accessible" pairing.
- Scale: body 16 (large 18 for amounts rows), label 14 min, title 20, amount headline 28 w/ tabular figures (`FontFeature.tabularFigures()`), line-height 1.5.
- Offline-first caveat: bundle font files as assets (not runtime fetch) so first launch offline works.

### Components
- Buttons: min 56dp height, full-width primary in forms, text label always visible (no icon-only for money actions).
- Nav: `NavigationBar` 4 destinations, labels always shown, selected indicator contrast >= 3:1.
- Money row: leading status icon, title, 2-line meta (who • when), trailing amount right-aligned tabular; whole row one `Semantics` node.
- Banners (sync/conflict/offline): icon + text + action, `liveRegion`, not color alone.
- Empty states: illustration-free, one sentence + one action (exists, keep).
- Motion: 150-250ms, fade/slide <=12dp, respect `MediaQuery.disableAnimations`.

### Theme skeleton (to implement in `wargakasTheme()`)
```dart
ThemeData wargakasTheme({Brightness brightness = Brightness.light}) {
  final scheme = ColorScheme.fromSeed(seedColor: const Color(0xff006b5b), brightness: brightness);
  final text = GoogleFonts.sourceSans3TextTheme().copyWith(
    headlineSmall: GoogleFonts.lexend(fontSize: 28, fontWeight: FontWeight.w600),
    titleLarge: GoogleFonts.lexend(fontSize: 20, fontWeight: FontWeight.w600),
    bodyLarge: GoogleFonts.sourceSans3(fontSize: 18, height: 1.5),
    bodyMedium: GoogleFonts.sourceSans3(fontSize: 16, height: 1.5),
  );
  return ThemeData(useMaterial3: true, colorScheme: scheme, textTheme: text,
    filledButtonTheme: FilledButtonThemeData(style: FilledButton.styleFrom(minimumSize: const Size.fromHeight(56))),
    // + cardTheme(outline), inputDecorationTheme(8 radius), navigationBarTheme, snackBarTheme
  );
}
```
