# Decisions

## Accepted

### 2026-08-24: Use GitHub As Persistent Project Memory

Decision: Keep the source of truth in the GitHub repository instead of Google Drive.

Reasoning:

- GitHub provides version history.
- The project memory can evolve alongside the application code.
- Future Codex sessions can clone the repo and resume from committed context.
