# Event Planner Agent Source of Truth

This folder is the persistent memory for the Event Planner Agent project.

Use these files as the first place to read before planning or building:

- `project-brief.md` captures the product vision, users, scope, and assumptions.
- `memory-log.md` records dated notes from working sessions.
- `decisions.md` tracks product and technical decisions.
- `backlog.md` tracks upcoming work and open questions.

## How To Keep This Current

1. Start each work session by reading this folder.
2. Add important discoveries to `memory-log.md`.
3. Record choices that affect future work in `decisions.md`.
4. Keep `backlog.md` focused on the next useful steps.
