# eventagent
Wargakas — a transparent shared cashbook for community events (trips, gatherings). Every contribution, expense, receipt and correction is traceable, so nobody has to suspect misuse of group money.

- App: `event-planner-agent/mobile` (Flutter: Android, iOS, web; 13 languages; 40+ currencies)
- Backend: `event-planner-agent/supabase` (Postgres + RLS, migrations, CI tests)
- Go-live, privacy policy, terms, store listing: `event-planner-agent/docs`
